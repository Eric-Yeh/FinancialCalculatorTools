貼上一個 GitHub 網址，下面就會列出可用的預覽鏈結。

使用前先知道

  • 預覽服務讀的是公開內容。私有 repo 一律開不起來，需要先公開或改用 GitHub Pages。
  • htmlpreview 靠瀏覽器端代理去抓相對路徑的資源，單一檔案很好用；一旦專案有大量 JS 模組、fetch 或 CORS 限制就容易破圖。
  • raw.githack.com 是開發用的即時網址、有流量上限；要給別人長期看，換成 rawcdn.githack.com 並把分支名改成 commit SHA，快取才會穩定。
  • jsDelivr 對 .html 可能以純文字回傳而不渲染，比較適合當 JS / CSS 的來源。要看畫面請優先用 githack 或 statically。
  • CDN 有快取。剛推上去的修改不會馬上反映，改動頻繁的階段建議用即時類網址。
  • 分支名含斜線（例如 feature/login）無法只從網址判斷，這裡會把第一段當成分支，必要時自己修一下。
  • 路徑指到資料夾時，這裡會自動補上 index.html。
